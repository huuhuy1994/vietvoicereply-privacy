# VietVoiceReply Privacy Pages

Bộ trang dành cho Huawei AppGallery:

- `privacy-policy.html` — URL chính sách bảo mật
- `data-subject-rights.html` — URL quyền của chủ thể dữ liệu
- `index.html` — trang điều hướng

## Trước khi công khai
1. Thay `[THAY EMAIL LIÊN HỆ CỦA BẠN]` bằng email hỗ trợ thật.
2. Upload toàn bộ các file HTML lên GitHub Pages, Cloudflare Pages, Vercel hoặc website riêng.
3. Dùng URL HTTPS công khai trong AppGallery.

Ví dụ GitHub Pages:
`https://USERNAME.github.io/vietvoicereply-privacy/privacy-policy.html`
`https://USERNAME.github.io/vietvoicereply-privacy/data-subject-rights.html`

KHÔNG upload thư mục AGC_SIGNING, file .p12, .csr hoặc credentials của dự án lên repository công khai.
